# GestorFFEOE – “Bienvenidos a las prácticas”

Aplicación web para la gestión de prácticas FCT en centros educativos, permitiendo administrar alumnos, empresas, profesores y asignaciones de plazas de forma centralizada.

##  Tecnologías

* **Backend:** PHP / Python
* **Frontend:** JavaScript
* **Base de Datos:** MySQL / PostgreSQL
* **Autenticación:** JWT
* **Documentación API:** Swagger/OpenAPI

##  Funcionalidades principales

* Gestión de ciclos, profesores y alumnado.
* Importación masiva mediante CSV.
* Gestión de empresas y plazas disponibles.
* Asignación dinámica de alumnos a empresas.
* Subida de CV y seguimiento del estado de prácticas.
* Sistema de roles: Administrador, Profesor y Alumno.

##  Objetivo del proyecto

Desarrollar una aplicación con arquitectura API-First, aplicando buenas prácticas de desarrollo, trabajo colaborativo con Git y revisión de código mediante Pull Requests.

##  Equipo

Proyecto realizado como práctica colaborativa en grupo para el módulo de desarrollo web.
